# Accordeur

Accordeur chromatique (+ guitare, ukulélé) en PWA, pour iPhone. Aucune dépendance.

Le micro n'est accessible que via **HTTPS** : héberger le dossier (ex. GitHub Pages), ouvrir l'URL dans Safari,
puis Partager → « Sur l'écran d'accueil ».

`node test.js` vérifie l'algorithme de détection (YIN).
